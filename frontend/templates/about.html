About Weather Music Generator

Our Vision

We aim to create a web application which will create unique MIDI compositions through an evolutionary algorithm. The compositions will be based on current weather data, leading to dynamic pieces with distinct differences depending on when the application is used. We thought this could serve as an elegant way of combining technological and natural forces, giving users a greater appreciation for the current weather.

Implementation

  • Primary programming language: Python
  • Weather data: Utilizing SMHI's APIs to collect current weather parameters (such as temperature, wind speed, precipitation and sunshine).
  • Location selection: The user selects from a set of locations (primarily cities, potentially also other locations) which tells the application what stations to gather the data from.
  • Evolutionary algorithm: We will code the algorithm ourselves. The weather data is used to decide the structure of the initial population of the EA, where each weather parameter influences different parts of the composition. The EA then proceeds to generate variations of the baseline or entirely new compositions over a number of generations.
  • Evaluation: Due to the subjective nature of how good a piece of music is, we are a bit uncertain about the choice of fitness function. Our current idea is to combine human evaluation (perhaps ranking a few provided pieces) with objective measurements such as repetitiveness of notes.
  • Output: A MIDI-file, containing the generated composition, for the user to save and play at their leisure.

Expected Results

We expect that our application will be able to produce dynamically varied compositions, due to basing the creation on something as shifting as the weather and transforming it using something as stochastic as an evolutionary algorithm.
